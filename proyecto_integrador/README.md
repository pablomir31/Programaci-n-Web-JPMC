## Instalación y Uso Local
1. Copiar la carpeta del proyecto dentro del directorio del servidor local (por ejemplo, htdocs en XAMPP o www en WampServer).

2. Iniciar los servicios de Apache y MySQL.

3. Abrir phpMyAdmin, crear una base de datos llamada biblioteca e importar el archivo biblioteca.sql.

4. Verificar las credenciales de conexión en config/conexion.php (por defecto usuario root sin contraseña).

5. Acceder desde el navegador a http://localhost/proyecto_integrador/.
